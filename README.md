# Duna Estudio

Web de un estudio de arquitectura con un hero cinematográfico: el video de la casa avanza al hacer scroll.

- Animaciones: [Motion](https://motion.dev) (la versión vanilla de Framer Motion)
- Partículas de niebla y brasas: [Three.js](https://threejs.org)
- Sin build: abre `index.html` o publícalo con GitHub Pages.
